# First Package

its the first written go file and try go commands

## Run

to run a go app we need

```bash
go run ./01-basics
```

## build

to build a go app and get the binaris we need
it gives us executable file

```bash
go build ./01-basics
```

## format

its the standard way to format a go code
go formatting is built into the ecosystem

```bash
go fmt ./...
```
